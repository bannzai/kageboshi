Kageboshi

影法師

上の画面に主人公、下の画面にその影。影は本体と同じ動きをする横スクロールアクション。

ただし、光が変わると影はずれる。上で避けた動きが、下では敵に飛び込む動きになる。

PC (Steam) 向けに開発中

同期が基本、ずれは条件付き

移動もジャンプも上下の画面でそろって動く。敵は上下どちらの画面にも現れ、どちらで当たってもダメージになる。そこに光と影の性質が、上下の動きをずらす瞬間を持ち込む。

光源の向きで反転する

松明や街灯をまたぐと影の伸びる向きが変わり、下の影だけ左右の動きが逆になる。

光源の高さで伸び縮みする

夕方の低い光では影が伸び、移動量や攻撃のリーチが大きくなる。真上の光では縮む。

影縫いで自分からずらす

ゲージを使って影を地面に縫い止め、本体だけを動かす。同期はタダ、ずれにはコストがかかる。

そろえれば強い

上下で同時に攻撃が当たると大ダメージになる。ずらせば避けやすく、そろえれば強い。ずれる区間は光の見た目や敵の予兆で前もって分かり、影を引き寄せればいつでも同期に戻れる。
